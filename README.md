# AI Resume Analyzer

## Project Overview

AI Resume Analyzer is an AI-powered web application built using Flask and Python that analyzes resumes, extracts important details, calculates an ATS compatibility score, identifies relevant skills, and helps candidates improve their resumes for job applications.

The system allows users to upload their resume in PDF format and provides an automated analysis report based on resume content and skills.

---

## Features

- Upload resume in PDF format
- Extract resume text automatically
- Analyze resume content
- Calculate ATS score
- Identify matched skills
- Identify missing skills
- Provide resume improvement suggestions
- Display analysis results through a web interface
